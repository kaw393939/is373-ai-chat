## Problem, objectives and preparation

Complete [preflight](README.md) and [data](../03-data.md). Know tables, indexes and transactions. The fixture disables type comparison in its private migration-environment copy so this experiment compares the index change. It does not establish full schema parity or PostgreSQL portability. ## Fixed fault and smallest repair

Restoring the metadata definition makes the scoped check pass. Identify why the same index can exist in SQL while being absent from the model contract.
